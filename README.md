# Pandas_practise

Pandas basic functions and short exercises collected in a single Jupyter notebook.

## What this repository contains

- `pandas.ipynb` — a self-contained Jupyter notebook that demonstrates core pandas concepts (Series, DataFrame), basic IO (read/write CSV), and small exercises. The notebook includes examples using:
  - pandas.Series and indexing
  - pandas.DataFrame creation from dictionaries and CSV files
  - reading a remote CSV (heart-disease dataset)
  - exporting and re-importing CSV (`exported_car_sales.csv`)

Note: the notebook references local files `car-sales.csv` and `exported_car_sales.csv`. `car-sales.csv` is not included in this repository; either provide it in the repository root or update the notebook to point to a valid CSV path.

## Quick start

1. Clone the repository:

```bash
git clone https://github.com/Elagnsuriyan/Pandas_practise.git
cd Pandas_practise
```

2. (Optional but recommended) Create a virtual environment and install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate   # macOS / Linux
.\.venv\Scripts\activate  # Windows (PowerShell)
python -m pip install --upgrade pip
pip install pandas jupyterlab
```

3. Open the notebook:

```bash
jupyter lab pandas.ipynb
# or
jupyter notebook pandas.ipynb
```

You can also view or run the notebook in Google Colab using the URL:

https://colab.research.google.com/github/Elagnsuriyan/Pandas_practise/blob/main/pandas.ipynb

Or view it directly on GitHub at:

https://github.com/Elagnsuriyan/Pandas_practise/blob/main/pandas.ipynb

## Notebook overview

The notebook contains short runnable examples and explanations; main sections include:

- Introduction: import pandas
- Series: creating Series from lists, dicts and arrays; indexing, iloc
- DataFrame: creating from dicts and CSVs; displaying with head() and basic describe/info
- IO examples: reading from a local `car-sales.csv`, exporting to `exported_car_sales.csv`, and re-loading that exported file
- Reading remote data: example loading a heart disease dataset from a remote URL
- Small exercises: building a DataFrame of fruits/prices

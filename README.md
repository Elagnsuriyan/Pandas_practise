# Pandas Practice

This repository is a beginner-friendly Pandas practice notebook focused on learning the core concepts of data manipulation with Python.

## Overview

The project contains a Jupyter Notebook, `pandas.ipynb`, that demonstrates:

- Creating and using `Series`
- Creating and using `DataFrame`
- Importing CSV data
- Exporting DataFrames to CSV
- Working with missing values (`NaN`)
- Reading data from external URLs
- Basic DataFrame examples and practice exercises
- Fundamentals of pandas data structures

## Repository Contents

- `pandas.ipynb` — main notebook with pandas examples and exercises

## Prerequisites

Before running the notebook, make sure you have Python installed along with the following packages:

```bash
pip install pandas jupyter notebook
```

## Running the Notebook

From the repository root, launch Jupyter:

```bash
jupyter notebook
```

Then open `pandas.ipynb` and run the cells in order.

## Learning Topics Covered

- Pandas `Series`
- Pandas `DataFrame`
- Data creation and manipulation
- CSV file handling
- Data inspection and display
- Basic examples for practice

## Example

```python
import pandas as pd

cars = pd.Series(['Lamborghini', 'BMW', 'Porsche'])
print(cars)
```

## Notes

This repository is intended for learning and hands-on practice with pandas basics. It is a simple educational project and is ideal for beginners who want to understand how pandas works in real examples.
